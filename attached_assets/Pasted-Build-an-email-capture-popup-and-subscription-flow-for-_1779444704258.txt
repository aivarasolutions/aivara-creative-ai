Build an email capture popup and subscription flow for the Aivara Solutions website.

Goal:
When a visitor comes to the website, show a professional branded popup asking them to subscribe for business automation, AI, marketing, and portal-building updates. When they submit their email, add them to our Mailchimp audience/list, then send them a branded welcome email using Resend from:

notifications@aivarasolutions.com

IMPORTANT:
- Do not hardcode API keys in the frontend.
- Mailchimp and Resend API calls must happen server-side only.
- Use environment variables for all private keys.
- Keep the popup, form, and welcome email fully branded with Aivara Solutions colors and logo.
- Use the existing Aivara Solutions logo already in the project assets.
- Match the current Aivara brand colors: magenta, purple, blue, teal, green, orange, and yellow gradients.
- Make the popup responsive on desktop and mobile.
- Make sure the popup does not annoy visitors by showing every page load.

--------------------------------------------------
2. MAILCHIMP INTEGRATION
--------------------------------------------------

Connect the popup form to Mailchimp.

Create a secure server-side endpoint, API route, or backend function:

POST /api/subscribe

The endpoint should:
1. Accept firstName, email, and interest.
2. Validate the email.
3. Add or update the subscriber in Mailchimp.
4. Add tags or merge fields based on interest.
5. Return success or error response to the frontend.
6. If Mailchimp succeeds, trigger the Resend welcome email.

Use these environment variables:

MAILCHIMP_API_KEY=
MAILCHIMP_SERVER_PREFIX=
MAILCHIMP_AUDIENCE_ID=

Optional merge fields:
FNAME = first name
INTEREST = selected business type / interest
SOURCE = Website Popup
COMPANY = Aivara Solutions Website

Mailchimp tags to add:
- Website Popup
- Aivara Lead
- The selected interest value, for example “AI Automation” or “Client Portals”

If the email already exists in Mailchimp:
- Update the contact instead of failing.
- Keep the flow user-friendly.
- Return a success message like they are subscribed.
