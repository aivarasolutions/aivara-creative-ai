--------------------------------------------------

or

Add helper functions like:

trackCTA(buttonText, location, destination)
trackLead(service, source, formType)

Each helper should:

- Send GA4 events if direct gtag is available.

- Never break the website if analytics is missing.

Use clean event parameters like:

{

  page_title,
  source,
  service,

  value
}
