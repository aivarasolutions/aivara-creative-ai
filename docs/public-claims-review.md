# Public Claims, References, and Logo Review

**Review date:** 2026-08-26  
**Scope:** public homepage, service and landing pages, portfolio data, and third-party tool/logo references.

## Review standard

No owner approval, release, result substantiation, or third-party endorsement evidence was present in the repository for public customer references, testimonials, quantified results, fixed implementation timing, availability promises, or platform/logo use. Those items must not be presented as substantiated advertising unless written evidence is added and reviewed.

## Disposition

| Item type | Public disposition | Evidence needed before re-publication |
| --- | --- | --- |
| Customer names, customer-style logo strips, and attributed testimonials | Removed. | Written customer permission that identifies the approved name/logo, exact quote, placement, duration, and any attribution. |
| Performance statistics and case-study outcomes | Removed or rewritten as clearly labelled illustrative project formats. | Source data, methodology/date range, and written approval for the exact public claim. |
| Implementation, response, delivery, and support availability promises | Rewritten as scope- and agreement-dependent. | An approved service-level commitment or documented basis for the stated timeframe. |
| Portfolio titles, alt text, URLs, and descriptions | Anonymized and rewritten as internal or illustrative examples. Third-party URLs were replaced with the contact route. | Written project-display permission for the named organization, screenshots, URL, and any claimed outcome. |
| Interface preview metrics and organization names | Replaced with sample data and “illustrative interface” context. | N/A unless production data or a customer identity is proposed for public display. |
| Third-party tool logos | Removed from the rendered page and local public logo directory. Tool names remain text-only with an explicit no-partnership/no-endorsement trademark notice. | Brand-usage approval or confirmed compliance with the relevant brand guidelines before restoring a logo. |
| Portfolio media files and external embeds | Public copy no longer identifies a customer or claims a result. The separate media-license/permission review governs whether those underlying media files and embeds may remain available. | License, creator/owner release, embed permission, and any client display authorization. |

## Ongoing publishing rule

Before adding a customer name, logo, testimonial, portfolio item, quantitative result, delivery time, availability commitment, comparison, or third-party logo to a public page, retain the supporting evidence and approval with the proposed copy. If the evidence does not support the precise statement and placement, use anonymized illustrative copy or do not publish it.
